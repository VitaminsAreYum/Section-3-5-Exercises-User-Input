# Section-3-5-Exercises-User-Input
In lesson 3-3 we learnt the difference between chars vs. strings, how to concatenate strings together, different types of escape sequences and how to better use print statements. 

In lesson 3-4 we learnt how Java does automatic promotion based on assignment and how to avoid issues with promotions, as well as how to cast variables and how to avoid issues with casting. We also learnt how to parse text to numerical data. 

In lesson 3-5 we learnt what user input is and why you would want it, as well as how to collect user input via dialog. We then learnt how to use a scanner to collect input from the console and a file, as well as how the scanner handles tokens and delimiters.
